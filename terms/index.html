1. The application

Dorado (‘Licensed Application’) is a piece of software created to support outdoor running and fitness tracking in a more immersive, game-like way, and customised for iOS and Android mobile devices (‘Devices’). It is a running app designed for tracking workouts and creating a motivating, immersive experience during exercise.

Furthermore, it is used to:

  • track a run while the user is moving;
  • show live progress, distance and rewards/coins;
  • provide dynamic audio and visual region changes during the run; and
  • keep the user engaged with a branded running experience and live activity updates while active.
